# 00. 開發規格書：計算機

> 這份文件說明「要做出什麼」，後面的章節說明「怎麼做」。開發過程中有任何「這裡該怎麼表現？」的疑問，都以本文件為準。

## 1. 專案目標

用 Angular 做一個網頁計算機：

- 輸入「數字1 運算子 數字2」，按 `=` 算出結果。
- 把結果加入下方的「計算結果 table」，並依照結果的數值套用不同的顯示樣式。

## 2. 技術規格

| 項目 | 規格 |
|---|---|
| 框架 | Angular 22（Standalone 元件、Signals、zoneless） |
| 語言 | TypeScript 6、HTML、CSS |
| 範本語法 | 內建控制流程 `@if`、`@for`（不用舊的 `*ngIf`、`*ngFor`） |
| 元件溝通 | `input()`、`output()` 函式（不用舊的 `@Input()`、`@Output()` 裝飾器） |
| 程式碼檢查 | ESLint（`angular-eslint`），`npm run lint` 必須零錯誤 |
| 自動排版 | Prettier，存檔時自動排版；`npx prettier --check .` 必須通過 |
| 單元測試 | Vitest（`ng test`），全部通過 |
| 編輯器 | VS Code（設定檔放在專案的 `.vscode/` 中） |

## 3. 畫面與元件架構

計算機畫面拆成 **4 個元件**：一個父元件（Component1）和三個子元件（Component2、3、4）。

```
┌──────────────── Component1：Calculator（父）─────────────────┐
│                                                                │
│   ┌───────── Component4：Display（算式列）─────────┐           │
│   │        113*3 = 339        [ = ] [ + ]          │           │
│   └────────────────────────────────────────────────┘           │
│                                                                │
│   ┌── Component2：NumberPad ──┐      ┌ Component3：OperatorPad ┐
│   │  [9] [8] [7]               │      │   [+]                   │
│   │  [6] [5] [4]               │      │   [-]                   │
│   │  [3] [2] [1]               │      │   [*]                   │
│   │  [0]                       │      │   [/]                   │
│   └────────────────────────────┘      │   [←]                   │
│                                        │   [C]                   │
│                                        └─────────────────────────┘
│                        [ clear ]                                │
│               ┌──────────────┬───┬──────────┐                   │
│               │     Ans      │   │          │  ← 計算結果 table │
│               ├──────────────┼───┼──────────┤                   │
│               │   NT$14.00   │   │ [delete] │                   │
│               │   -NT$5.00   │ * │ [delete] │                   │
│               │  NT$339.00   │ * │          │                   │
│               └──────────────┴───┴──────────┘                   │
└────────────────────────────────────────────────────────────────┘
```

| 元件 | 類別名稱 | 選擇器（HTML 標籤） | 資料夾 | 負責 |
|---|---|---|---|---|
| Component1 | `Calculator` | `<app-calculator>` | `src/app/calculator/` | **父元件**。保存所有資料（算式、結果、table 資料），處理子元件傳上來的事件；`clear` 按鈕與結果 table 也放在這裡 |
| Component2 | `NumberPad` | `<app-number-pad>` | `src/app/number-pad/` | 0–9 數字鍵 |
| Component3 | `OperatorPad` | `<app-operator-pad>` | `src/app/operator-pad/` | `+ - * /` 運算子鍵、`←`、`C` |
| Component4 | `Display` | `<app-display>` | `src/app/display/` | 顯示算式與結果，以及 `=`、`+` 兩個按鈕 |

另有一個不屬於畫面的檔案 `src/app/calc.ts`：放計算與判斷的**純函式**（輸入相同就一定得到相同結果，方便測試）。

### 3.1 資料流（父子元件怎麼溝通）

**資料由父元件往下傳（input），事件由子元件往上傳（output）。** 子元件不保存資料，也不自己做計算。

```
                     Calculator（父）
          保存：expression、result、message、records
            │ input ↓                          ↑ output
            │                                  │
   ┌────────┴─────────┐   ┌────────────────────┴──────────────────────┐
   │ Display          │   │ NumberPad   → digit(數字)                   │
   │ ↓ expression     │   │ OperatorPad → operator(運算子)、backspace、  │
   │ ↓ result         │   │               clearExpression              │
   │ ↓ message        │   │ Display     → equals、add                   │
   └──────────────────┘   └─────────────────────────────────────────────┘
```

| 元件 | input（父 → 子） | output（子 → 父） |
|---|---|---|
| NumberPad | — | `digit: string`：按下的數字 |
| OperatorPad | — | `operator: string`：按下的運算子；`backspace`：按下 `←`；`clearExpression`：按下 `C` |
| Display | `expression: string` 算式；`result: number \| null` 結果；`message: string` 錯誤訊息 | `equals`：按下 `=`；`add`：按下 `+` |

## 4. 功能需求

### 4.1 算式列（Component4）

顯示格式：`數字1 運算子 數字2 = 計算結果 [=] [+]`，例如 `113*3 = 339`。

| 編號 | 操作 | 規則 |
|---|---|---|
| F-01 | 按數字鍵 | 把數字接到算式最後面 |
| F-02 | 按運算子鍵 | 算式是空的 → 不動作；最後一個字已經是運算子 → **替換**成新的運算子；算式已經有運算子且輸入了數字2 → 不動作（只算兩個數字） |
| F-03 | 按 `=` | 算式完整時算出結果，顯示在 `=` 後面；加千分位，小數最多顯示 2 位（例如 `2,468`、`3.33`） |
| F-04 | 按 `=`，但算式不完整（例如 `5+`）或除以 0 | 不顯示結果，顯示紅色訊息「無法計算」 |
| F-05 | 按 `+`（算式列上的） | 把目前的計算結果新增到 table 最下面。**還沒有結果時按鈕停用（灰色、不能按）** |
| F-06 | 按 `←` | 刪除算式最後一個字（數字或運算子） |
| F-07 | 按 `C` | 清空算式 |
| F-08 | 算式有任何變動（F-01、02、06、07） | 舊的結果與錯誤訊息一起清除，需要重新按 `=` |

> 📝 原始需求中的範例 `1+1=1` 是筆誤，正確應為 `1+1=2`。

### 4.2 計算結果 table

| 編號 | 規則 | 範例 |
|---|---|---|
| T-01 | 結果為**偶數** → 該列**灰底** | 14、-6 |
| T-02 | 結果為**奇數** → 第 2 欄顯示 `*` | 339、-5 |
| T-03 | 結果為**負數** → **紅字** | -NT$5.00 |
| T-04 | 結果為**正數** → **綠字** | NT$14.00 |
| T-05 | 金額格式化成**台幣**：`NT$` 加千分位、小數 2 位 | 1234 → `NT$1,234.00` |
| T-06 | 每列都有 `delete` 按鈕，按下刪除**該筆** | — |
| T-07 | 結果**大於 100** 的列**不顯示** `delete` 按鈕 | 339 沒有 delete；100 有 |
| T-08 | 按 table 上方的 `clear` → 刪除 table **全部**資料 | — |
| T-09 | table 沒有資料時顯示「尚無資料」 | — |

**判定細節**

- 0 是偶數（灰底），但既不是正數也不是負數，所以用預設文字顏色。
- 有小數的結果（例如 `10/4 = 2.5`）**既不是偶數也不是奇數**：不灰底、不顯示 `*`。
- 「大於 100」不包含 100 本身。

## 5. 畫面樣式

| 部位 | 樣式 |
|---|---|
| 外框 | 米色（`#dfc9a8`）圓角面板，帶陰影，在頁面上水平置中 |
| 算式列 | 灰色（`#e0e0e0`）膠囊形，帶陰影 |
| 數字鍵 | 3 欄方格排列（9 8 7 / 6 5 4 / 3 2 1 / 0） |
| 運算子鍵 | 在數字鍵右側直排 |
| table | 細黑框線；偶數列灰底 `#d9d9d9`；正數綠字 `#2e7d32`；負數紅字 `#d32f2f` |

## 7. 驗收條件

全部打勾才算完成：

- [ ] 輸入 `113*3` 按 `=`，算式列顯示 `113*3 = 339`
- [ ] 再按 `+`，table 新增一列 `NT$339.00`：綠字、有 `*`、**沒有** delete
- [ ] `5-10` → `=` → `+`：`-NT$5.00` 紅字、有 `*`、有 delete
- [ ] `7*2` → `=` → `+`：該列灰底、沒有 `*`
- [ ] `10/4` → `=` → `+`：`NT$2.50`，不灰底、沒有 `*`
- [ ] `8/0` → `=`：顯示「無法計算」，`+` 不能按
- [ ] 按 `5`，再連按 `+`、`*`，算式顯示 `5*`（運算子被替換）
- [ ] `←` 一次刪一個字；`C` 清空算式
- [ ] `delete` 只刪除該列；`clear` 清空 table，並顯示「尚無資料」
- [ ] `npm run lint` 零錯誤
- [ ] `npx prettier --check .` 通過
- [ ] `ng test --watch=false` 全部通過
- [ ] `ng build` 成功
